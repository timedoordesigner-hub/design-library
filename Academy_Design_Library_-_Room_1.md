## Cara pakai

- Total entri: **513** file desain (kolom `No` 1–527).

- Kolom `Category` dan `Tipe Media` bisa berisi beberapa nilai dipisah koma.
- `Link File` mengarah ke file Figma (node tertentu). `Preview` adalah nama file gambar preview (.png).
- `Keyword` dipakai untuk pencarian; `Note` berisi catatan penggunaan (opsional, hanya terisi di sebagian entri).
- Entri tanpa link: No 444, 445, 446.
